# Logos de operadores

Coloca aquí archivos **`{slug}.png`** o **`{slug}.svg`**. El slug coincide con `operatorLogoSlug` en la API (por ejemplo `fred-olsen-express`).

La UI intenta primero `.png` y luego `.svg`. Si no hay fichero, el hueco del logo simplemente no se muestra.

Lista de slugs: ver `docs/CANARY_FERRY_OPERATORS_AND_LOGOS.md`.
